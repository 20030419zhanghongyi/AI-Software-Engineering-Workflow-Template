# STOP_CONDITIONS.md

> 必须暂停执行的条件。暂停不是失败，是为了防止错误继续扩大。

---

## 核心原则

```text
宁可多暂停一次，不要让错误继续扩大。
暂停后必须报告原因，等待指示再继续。
```

---

## 必须暂停的条件

### 1. 修改禁止文件

Agent 试图修改任务卡中 Forbidden Files 列出的文件。

**应做**：暂停，在检查点报告中报告，等待监督 Agent 决定是否更新边界。

### 2. 范围扩大

Agent 在执行任务过程中，发现需要做超出原始任务范围的工作。

**应做**：暂停，报告范围扩大的原因和建议，不要擅自执行。

### 3. 核心架构变化

修改涉及 docs/04_architecture.md 中定义的"关键约束"或"禁止破坏的架构规则"。

**应做**：暂停，生成 Human Brief，让用户决定。

### 4. 引入新依赖

任务需要引入项目当前未使用的新依赖包。

**应做**：暂停，说明为什么需要引入、考虑过哪些替代方案，等待确认。

### 5. 测试失败

测试失败但 Agent 想继续扩展功能。

**应做**：暂停，先修复导致测试失败的问题，不要继续添加新功能。

### 6. UI 体验偏离

UI / 交互结果明显偏离用户预期（或已有设计稿）。

**应做**：暂停，在检查点报告中截图对比，等待反馈。

### 7. 多 Agent 冲突

多个 Agent 需要修改同一核心文件。

**应做**：暂停所有涉及该文件的 Agent，由监督 Agent 协调。

### 8. 输出不足以判断风险

修改的影响范围不明确，无法判断是否会破坏其他功能。

**应做**：暂停，补充信息后再继续。

### 9. 合并前存在冲突

合并前发现不同 Agent 的修改存在冲突。

**应做**：暂停，列出冲突详情，由监督 Agent 协调解决顺序。

### 10. 其他在意不确定

遇到任何不确定的情况，不确定正确的做法。

**应做**：暂停，报告不确定性，请求指示。这不是软弱，是谨慎。

### 11. 问题未验证却开始实现（v0.2 新增）

Idea Gate 未通过，却已经开始写代码。

**应做**：暂停，先用 validate-idea Skill 完成 Idea Gate。

### 12. MVP 范围失控（v0.2 新增）

实现过程中功能不断"顺便加上"，Out of scope 列表被持续突破。

**应做**：暂停，回到 MVP Gate 重新确认范围。新增功能必须放到下一轮。

### 13. Antigravity 想执行高风险命令（v0.2 新增）

Antigravity 想执行删除、修改配置、网络请求等高风险终端命令，未经人工确认。

**应做**：暂停，生成 Human Brief，等待 Human Owner 确认。

### 14. 想跳过 Plan Artifact（v0.2 新增）

Agent 想跳过 Plan Artifact 直接执行代码修改。

**应做**：暂停，先生成 Plan Artifact 并等待人工确认。

### 15. 想跳过 Human Review（v0.2 新增）

Agent 想跳过人工审查直接进入下一阶段。

**应做**：暂停，必须等待 Human Owner 确认后才能继续。

### 16. CI 失败却想继续 merge（v0.2 新增）

CI 未通过，但 Agent 建议继续 merge。

**应做**：暂停，修复 CI 问题后再 merge。CI 是质量底线，不能绕过。

### 17. Launch 指标未定义却想发布（v0.2 新增）

Launch Gate 中核心指标未定义，但 Agent 或用户想直接发布。

**应做**：暂停，先定义至少 1 个核心指标和阈值。

### 18. 盲目自动化（v0.2 新增）

Scale Gate 中对未验证的流程进行自动化，或自动化了需要人判断的步骤。

**应做**：暂停，回到手动流程，先验证流程有效性再考虑自动化。

---

## 暂停后的标准操作

1. **报告**：在检查点报告中说明暂停原因。
2. **上下文**：提供足够的上下文信息，让监督 Agent / 用户能做出判断。
3. **建议**：如果 Agent 有建议的处理方式，可以在报告中提出，但不要自行执行。
4. **等待**：等待监督 Agent 或用户的指示后再继续。

---

## 不需要暂停的情况

以下情况不需要暂停：

- 代码格式化或自动 fix（不影响逻辑）
- 补充注释或文档（不修改源码逻辑）
- 修复明显的 typo
- 按任务计划正常完成的工作

但如果这些操作意外影响了其他功能，仍需按上述条件暂停。
