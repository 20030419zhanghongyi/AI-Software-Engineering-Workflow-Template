# LocalMarkdownNote

## 项目是什么

一个本地 Markdown 笔记管理桌面应用，支持标签、全文搜索和实时预览。所有数据存储在本地，不需要网络连接。

## 目标用户

个人开发者、写作者、研究人员——需要在本地管理大量 Markdown 笔记的人。

## 核心问题

现有笔记工具要么需要联网，要么不支持纯 Markdown，要么搜索太慢。我需要一个轻量、本地、快速的 Markdown 笔记管理工具。

## 核心功能

- [x] Markdown 文件夹扫描和索引
- [x] 全文搜索（基于 SQLite FTS5）
- [ ] 标签系统
- [ ] 实时预览
- [ ] 笔记导出（PDF / HTML）

## 不做什么

- 不做云同步
- 不做多人协作
- 不做富文本编辑
- 不做移动端
- 不做插件系统
