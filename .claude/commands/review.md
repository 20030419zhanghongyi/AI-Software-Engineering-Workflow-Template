# /review Command

> 审查 diff / 修改结果。

---

## Command Template

```markdown
请审查当前的所有代码修改。

审查要点：

1. **变更范围**：修改了哪些文件？是否在任务允许范围内？
2. **越权检查**：是否修改了 forbidden files？是否有无关重构？
3. **架构影响**：是否违反了架构约束？是否破坏了模块边界？
4. **依赖变更**：是否引入了新依赖？是否有正当理由？
5. **测试覆盖**：修改是否有对应的测试？测试是否通过？
6. **代码质量**：是否符合编码规范？是否有明显问题？
7. **风险**：可能的副作用？回滚方案？

输出审查报告，给出建议：通过 / 小修后通过 / 需要返工。
```

---

## Usage

在 Claude Code 中，当你想审查 AI 的修改结果时，使用此命令。

适用于：

- AI 完成任务后，想审查整体修改
- 合并前想检查代码质量
- 不确定 AI 的修改是否正确时
