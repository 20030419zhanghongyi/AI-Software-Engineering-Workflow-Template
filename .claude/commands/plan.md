# /plan Command

> 让 Claude 先输出执行计划，不要直接改代码。

---

## Command Template

```markdown
请先输出执行计划，不要直接修改代码。

计划应包含：

1. **任务理解**：用自己的话重述任务目标，确认没有理解偏差。
2. **计划修改的文件**：列出需要修改的文件和每个文件的修改原因。
3. **实现步骤**：按步骤说明实现方式。
4. **边界检查**：确认所有修改都在任务允许范围内，没有越权修改。
5. **风险**：可能的副作用和风险。
6. **需要确认**：是否有需要人工确认的点。

等待我确认后再开始修改代码。
```

---

## Usage

在 Claude Code 中，当你想让 AI 先输出计划而不是直接改代码时，使用此命令。

适用于：

- 接到新任务时
- 不确定 AI 会怎么改时
- 任务涉及多个文件时
- 想审查 AI 的思路时
