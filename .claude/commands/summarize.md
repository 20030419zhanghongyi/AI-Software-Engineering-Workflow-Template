# /summarize Command

> 总结本轮任务的执行情况。

---

## Command Template

```markdown
请总结本轮任务的执行情况。

总结应包含：

1. **任务目标**：本轮任务要完成什么。
2. **完成情况**：哪些已完成，哪些未完成。
3. **修改文件清单**：
   | 文件 | 变更类型 | 原因 |
   |------|---------|------|
4. **测试结果**：运行了哪些测试，结果如何。
5. **未完成项**：如有未完成的工作，列出 TODO。
6. **技术债**：是否产生了新的技术债。
7. **后续建议**：建议的下一步工作。
8. **复盘要点**：本轮任务中值得记录的经验教训。
```

---

## Usage

在 Claude Code 中，当一轮任务结束时，使用此命令生成总结。

适用于：

- 一个 Issue 完成后
- 一个功能迭代结束后
- 准备提交 PR 前
- 一天工作结束时
